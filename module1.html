Computing with MATLAB

Implement numerical techniques in MATLAB. Before we can solve hard numerical problems, we need a fluent command of the tool: the environment, arrays, programming constructs, vectorization, and the limits of finite-precision arithmetic.

📘 Chapra Ch. 2 & 3 ⏱ Weeks 1–3 🧪 Assessed by Quiz 1 & Lab

Why MATLAB for scientific computing?

MATLAB — short for MATrix LABoratory — is both an interactive computing system (type a command, get an answer immediately) and a programming language. Its native data type is the matrix, which makes it a natural fit for numerical methods, where almost everything reduces to operations on vectors and matrices.

In this module you will learn just enough of the language to implement every method in the rest of the course. The recurring theme is simple: think in arrays, not loops.

💡 Big idea
Numerical methods turn calculus and algebra into arithmetic that a computer can repeat. MATLAB is the machine we use to repeat it accurately and fast.

1.1 The MATLAB environment

When you open MATLAB you meet four key panels: the Command Window (type commands, see results), the Workspace (the variables currently in memory), the Editor (where you write .m script and function files), and the Current Folder browser.

Two commands you will use constantly:

  • clc — clear the command window (tidy the screen).
  • clear — remove all variables from the workspace (start fresh).

A trailing semicolon ; suppresses output. Without it, MATLAB echoes the result of every line — useful while debugging, noisy in finished code.

Printing results

Use disp for quick output and fprintf for formatted output. Format specifiers: %d (integer), %f (float), %.2f (2 decimals), \n (new line).

1.2 Matrices and vectors

Everything in MATLAB is an array. A scalar is a \(1\times 1\) array, a row vector is \(1\times n\), a column vector is \(n\times 1\), and a matrix is \(m\times n\).

  • Square brackets [ ] build arrays. Spaces (or commas) separate columns; semicolons separate rows.
  • zeros(m,n) and ones(m,n) pre-build arrays of a known size — important for preallocation.
  • The colon operator start:step:stop generates evenly spaced vectors.

📐 Definition · column-major order
MATLAB stores matrices column by column in memory. A(:) flattens a matrix into a single column by reading down each column in turn. This matters for linear indexing and for writing fast code.

Element-wise vs. matrix operations

This is the single most common source of beginner errors. A dot before *, /, or ^ means “do it element by element”. Without the dot, MATLAB performs the linear-algebra operation.

Element-wise (with dot)
x .* y · x ./ y · x .^ 2
Each element combined with the matching element. Arrays must be the same size.
Matrix (no dot)
A * B · A ^ 2 · A \ b
True matrix multiply, power, and solve. Inner dimensions must agree.

Logical indexing — selecting with conditions

Logical indexing is one of the most powerful ideas in MATLAB — and one of the most confusing the first time you meet it. Once it clicks, entire loops collapse into a single readable line. The secret is to stop reading v(v > 0) as one mysterious thing and instead see it as three separate steps that happen in order.

📐 The three-step mental model
① Compare. A condition such as v > 0 is tested at every element at once, producing a logical mask: an array the same size as v holding only true (1) or false (0).
② Mask. That mask records which positions passed the test — it is a genuine array you can store and look at.
③ Apply. Use the mask as an index to read the marked elements (v(mask)) or to write them (v(mask) = …). Everything not marked is left untouched.

The step people skip is ①→②: the comparison is not a question, it is an array. Store it and print it to see for yourself:

Reading vs. writing with a mask

Once you have a mask, the same square brackets do two very different jobs depending on which side of the = the indexed array sits.

  • Read / select: pos = v(v>0) — pulls the marked elements out into a new (usually shorter) vector.
  • Write / modify in place: v(v<0) = 0 — overwrites only the marked elements and leaves the rest exactly as they were. The right-hand side is either one scalar (broadcast to all marked spots) or an array with as many values as there are trues in the mask.

2-D logical indexing — and the shape trick everyone trips on

Here is the question that confuses almost everyone the first time. If A is a \(3\times3\) matrix and the mask A>15 is also \(3\times3\), what shape does A(A>15) return — a matrix, or a vector?

⚠️ The answer: always a column vector
Selecting from a matrix with a logical mask always flattens the result to a column vector — never a matrix. MATLAB walks the matrix in column-major order (down column 1, then column 2, …) and stacks every element that passed into one tall \(k\times1\) column. It cannot stay rectangular, because in general a different number of elements pass in each row.

Read the order carefully: 22 (row 2, col 1) comes before 17 (row 1, col 2), because MATLAB finishes column 1 before starting column 2. The three positions are therefore \((2,1),(1,2),(3,3)\).

💡 Writing keeps the shape — reading does not
The flattening only happens when you read. When you assign with a mask, the matrix keeps its \(m\times n\) shape — only the marked cells change:
A(A > 15) = 15; leaves A as a \(3\times3\) matrix with the three large entries clamped to 15.

The most useful 2-D trick: select whole rows or columns

Often you don't want scattered elements — you want the rows (records) that satisfy a condition. Build a logical vector as long as there are rows, then index the first dimension and use : for the second. This is the everyday pattern for filtering a data table.

MATLAB · editable · keep whole rows
Command Window output
passMask =

  4×1 logical array

   0

   88   30

Because the second index is : (all columns), each selected row stays intact — so the result is a matrix. The mirror image, A(:, colMask), keeps whole columns. This “mask one dimension, colon the other” idea is how you filter records without a single loop.

🛠 Quick summary of shapes
A(A>5) → column vector (flattened, column-major).
A(A>5) = 0 → same matrix shape, marked cells changed.
A(rowMask, :) → whole rows kept (still a matrix).
A(:, colMask) → whole columns kept.
find(A>5) → linear indices; [r,c] = find(A>5) → row/column subscripts.

Combining conditions: & and |

Real filters usually need more than one test. Join masks element-wise with & (and — both must pass) or | (or — either passes). You can build a two-sided band this way. (Try the "add 2nd condition" box in the demo above.)

⚠️ Four classic traps
1. Use & and |, not && / || for arrays — the double forms are for single true/false values and will error or mislead on vectors.
2. Mind the parentheses: write v(v>=0 & v<=5); comparison and & mix in a way that often needs them.
3. Mask size must match the array it indexes — it comes from a comparison on that same array, so this is automatic unless you mix arrays.
4. Positions vs. values: v(v>0) gives the values; use find(v>0) when you need the indices.
⚡ Useful aggregators
sum(A), sum(A,2) (row sums), reshape(A,m,n), A(:) (flatten), and matrix multiply A*B all replace nested loops. The triple-loop matrix multiply is a classic example: C = A*B; does the same job in one line and orders of magnitude faster.

1.6 Matrix slicing — rows, columns & blocks

Indexing a matrix uses two positions: A(rows, cols). Put a list or range in either position to grab many entries at once. The colon : means "all", and end means "the last one". The same expression can read a slice (on the right of =) or overwrite it (on the left).

📐 The three shapes you slice out
A row block — one or more whole rows: A(2:3, :). A column block — one or more whole columns: A(:, 3). A rectangular block in the middle — a range of rows crossed with a range of columns: A(2:3, 2:4).

Reading a slice

MATLAB
A = [11 12 13 14 15
     21 22 23 24 25
     31 32 33 34 35
     41 42 43 44 45
     51 52 53 54 55];

r  = A(2, :)        % whole 2nd row      -> [21 22 23 24 25]
c  = A(:, 3)        % whole 3rd column   -> [13; 23; 33; 43; 53]
B  = A(2:3, 2:4)    % block rows 2-3, cols 2-4 -> [22 23 24; 32 33 34]
z  = A(end, end)    % bottom-right entry -> 55

Modifying a slice

Assign into a slice to overwrite it. The right-hand side must match the block's size — or be a single number, which fills the whole block.

MATLAB
A(1, :)      = 0;              % set the whole 1st row to 0
A(:, 4)      = [1; 2; 3; 4; 5]; % overwrite the 4th column
A(2:3, 2:4)  = 99;             % fill the middle block with 99
A(4:5, 4:5)  = [1 2; 3 4];     % overwrite a 2x2 block (sizes must match)
A(2, :)      = [];             % DELETE the 2nd row (rows below shift up)
A(:, 3)      = [];             % DELETE the 3rd column
⚠️ Size must match
When you write A(2:3, 2:4) = M, the right side M must be exactly 2×3 (or a single number). Deleting with = [] only works for whole rows or whole columns, never a middle block — MATLAB cannot leave a hole.

Reveal answer
function m = average(v)
    m = sum(v) / length(v);
end
The file name must match the function name (average.m), and the file is created as a script in the Editor, not typed in the Command Window. call it from another file/script: average([2 4 6]) → 4
