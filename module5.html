Numerical Integration & ODEs

Solve differential equations using numerical integration. We approximate definite integrals by summing simple shapes, then use the same idea to march the solution of an ordinary differential equation forward in time.

📘 Chapra Ch. 19, 20, 22, 23 ⏱ Weeks 12–15 🧪 Assessed by Quiz 2, Lab final & Final

The definite integral as area

🔊 Listen to this section

A definite integral is the area under the curve between two limits:

\[ I = \int_a^b f(x)\,dx. \]

For complicated or non-elementary functions there is often no analytic antiderivative. Numerical integration (quadrature) approximates the area by breaking \([a,b]\) into subintervals and summing the areas of simple shapes — rectangles, trapezoids, or parabola-capped strips — that hug the curve.

All the rules below split the interval into \(n\) segments of width

\[ \Delta x = \frac{b-a}{n}. \]

5.1 The midpoint rule

🔊 Listen to this section

Approximate each strip by a rectangle whose height is the function value at the midpoint of that strip:

\[ I \approx \Delta x \sum_{k} f(m_k), \qquad m_k = \text{midpoint of strip } k. \]
  1. Compute \(\Delta x = (b-a)/n\).
  2. Find the midpoint of each subinterval.
  3. Evaluate \(f\) at every midpoint, sum, and multiply by \(\Delta x\).

Worked example

🔊 Listen to this example

Approximate \(\int_0^{10} x^3\,dx\) with \(n=5\). Then \(\Delta x = 2\) and the midpoints are \(1,3,5,7,9\):

\[ S = 1^3+3^3+5^3+7^3+9^3 = 1+27+125+343+729 = 1225, \]
\[ I \approx \Delta x \cdot S = 2(1225) = 2450 \quad(\text{exact } 2500,\ \text{error } 2\%). \]

5.2 The trapezoidal rule

🔊 Listen to this section

Connect adjacent points with straight lines and sum the resulting trapezoids. The interior points are counted twice (each is shared by two trapezoids), giving the weighting \(1,2,2,\dots,2,1\):

\[ I \approx \frac{\Delta x}{2}\Bigl[\,f(x_0) + 2\sum_{i=1}^{n-1} f(x_i) + f(x_n)\,\Bigr]. \]

Worked example

🔊 Listen to this example

Approximate \(\int_0^{8} x^2\,dx\) with \(n=4\), so \(\Delta x = 2\) and grid points \(0,2,4,6,8\):

\[ S = f(0)+f(8) + 2\bigl[f(2)+f(4)+f(6)\bigr] = 0 + 64 + 2(4+16+36) = 176, \]
\[ I \approx \frac{\Delta x}{2}\,S = \frac{2}{2}(176) = 176 \quad(\text{exact } 170.67). \]

5.3 Simpson's 1/3 rule

🔊 Listen to this section

Instead of straight lines, fit a parabola through each pair of strips. This is far more accurate for smooth functions. With an even number of segments, the weighting pattern is \(1,4,2,4,\dots,4,1\):

\[ I \approx \frac{\Delta x}{3}\Bigl[\,f(x_0) + 4\!\!\sum_{i\,\text{odd}}\!\! f(x_i) + 2\!\!\sum_{i\,\text{even}}\!\! f(x_i) + f(x_n)\,\Bigr]. \]
💡 Accuracy ladder
Midpoint & trapezoid are exact for straight lines (low order). Simpson is exact for cubics — for the same number of points it is typically far more accurate. That extra accuracy comes free, just from smarter weights.

5.4 Gaussian & adaptive quadrature

🔊 Listen to this section

Gaussian quadrature drops the requirement of equally spaced points. By choosing both the sample locations and their weights optimally, an \(n\)-point Gauss rule integrates polynomials up to degree \(2n-1\) exactly — remarkable accuracy from very few evaluations.

Adaptive quadrature puts the effort where the function is hard: it subdivides only the regions where the estimate is still changing, using many small strips on wiggly parts and few large strips on smooth parts. MATLAB's integral is adaptive.

We also handle improper integrals (infinite limits or integrable singularities) by transformation or by special adaptive handling near the trouble spot.

5.5 Ordinary differential equations

🔊 Listen to this section

A differential equation relates an unknown function to its derivatives. A first-order initial-value problem has the form

\[ \frac{dy}{dx} = f(x,y), \qquad y(x_0) = y_0. \]

The derivative tells us the slope of the solution at every point; the initial condition pins down which specific curve we are on. Integrating \(dy/dx\) alone gives a family of curves differing by a constant \(c\); the initial value selects one.

📐 Example
From \(dy/dx = -20x + 8.5\) we get \(y = -10x^2 + 8.5x + c\). The initial condition \(y(0)=1\) fixes \(c=1\), so \(y = -10x^2 + 8.5x + 1\).

When \(f(x,y)\) has no closed-form solution, we march forward in small steps of size \(h\), using the slope to predict the next value — the same “sum small pieces” idea as integration.

5.6 Euler's method

🔊 Listen to this section

The simplest one-step method. From the current point, follow the slope \(f(x_i,y_i)\) in a straight line for one step of width \(h\):

\[ y_{i+1} = y_i + h\,f(x_i, y_i), \qquad x_{i+1} = x_i + h. \]

Each step uses a tangent-line approximation, so Euler accumulates error: it is first-order (halving \(h\) roughly halves the error). Smaller steps are more accurate but cost more evaluations.

5.7 Runge–Kutta & higher-order methods

🔊 Listen to this section

Euler uses the slope only at the start of each step. Runge–Kutta methods sample the slope several times across the step and combine them, capturing curvature Euler misses. The classic RK4 averages four slope estimates:

\[ y_{i+1} = y_i + \frac{h}{6}\bigl(k_1 + 2k_2 + 2k_3 + k_4\bigr), \]
\[ k_1 = f(x_i,y_i),\ \ k_2 = f\!\left(x_i+\tfrac{h}{2}, y_i+\tfrac{h}{2}k_1\right),\ \ k_3 = f\!\left(x_i+\tfrac{h}{2}, y_i+\tfrac{h}{2}k_2\right),\ \ k_4 = f(x_i+h, y_i+hk_3). \]

RK4 is fourth-order: halving \(h\) cuts the error by about 16×. For the same accuracy it needs far larger steps than Euler.

  • Adaptive step size: automatically shrink \(h\) where the solution changes fast and grow it where it is smooth (MATLAB's ode45 does this).
  • Coupled / higher-order ODEs: rewrite an \(n\)-th-order equation as a system of \(n\) first-order equations and march the whole vector forward together.

Practice examples

One example per topic (5.1–5.7). Work on paper, then reveal. The three quadrature rules use the same integral \(\int_0^4 (x^2+1)\,dx\) (exact = 25.333).

✏️ 5.1 Midpoint rule
Estimate ∫₀⁴ (x² + 1) dx with n = 4 (h = 1; midpoints 0.5, 1.5, 2.5, 3.5).
Reveal answer
f at midpoints = 1.25, 3.25, 7.25, 13.25
\(M=h\sum f = 1\,(1.25+3.25+7.25+13.25)\) M = 25.000 (exact = 25.333)
✏️ 5.2 Trapezoidal rule
Same integral, n = 4 (nodes 0,1,2,3,4; f = 1,2,5,10,17).
Reveal answer
\(T=\dfrac{h}{2}\big[f_0+f_4+2(f_1+f_2+f_3)\big]=\dfrac12[1+17+2(2+5+10)]=\dfrac12(52)\) T = 26.000 (exact = 25.333)
✏️ 5.3 Simpson's 1/3 rule
Same integral, n = 4.
Reveal answer
\(S=\dfrac{h}{3}\big[f_0+f_4+4(f_1+f_3)+2f_2\big]=\dfrac13[1+17+4(2+10)+2(5)]=\dfrac13(76)\) S = 25.333 — exact, because Simpson is exact for cubics
✏️ 5.4 Gaussian & adaptive quadrature
Use 2-point Gauss–Legendre (nodes \(\pm 1/\sqrt3\), weights 1, 1) to evaluate \(\int_{-1}^{1} x^{2}\,dx\).
Reveal answer
\(\int_{-1}^{1} x^{2}\,dx \approx 1\!\cdot\!f(-1/\sqrt3)+1\!\cdot\!f(1/\sqrt3)=\tfrac13+\tfrac13=\mathbf{0.6667}\) — exact.
An \(n\)-point Gauss rule is exact for polynomials up to degree \(2n-1\); adaptive quadrature adds points only where the curve bends, to hit a tolerance efficiently. 2 points, yet exact up to degree 3 — that is why Gauss is so efficient
✏️ 5.5 Ordinary differential equations
What does the initial-value problem \(y'=f(x,y),\ y(x_0)=y_0\) ask for, and why not just integrate directly?
Reveal answer
It asks for the function \(y(x)\) whose slope everywhere equals \(f(x,y)\) and that passes through \((x_0,y_0)\).
When \(f\) depends on the unknown \(y\) itself, there is usually no closed-form antiderivative, so we march forward numerically: start at \((x_0,y_0)\) and take small slope-guided steps. the ODE gives the slope field; a solution is a curve tangent to it

✏️ 5.7 Runge–Kutta & higher-order methods
Why is classical RK4 preferred over Euler at the same step size h? What is its error order?
Reveal answer
RK4 samples the slope four times per step (start, two midpoints, end) and takes a weighted average, matching the Taylor series to 4th order.
Global error is \(O(h^{4})\) versus Euler's \(O(h)\), so it reaches the same accuracy in far fewer steps. MATLAB's ode45 is an adaptive Runge–Kutta method. more slope samples per step ⇒ much smaller error for the same h
